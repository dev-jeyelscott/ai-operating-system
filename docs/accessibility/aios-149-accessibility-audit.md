# AIOS-149 Accessibility Audit

## Audit metadata

- Ticket: AIOS-149
- Standard: WCAG 2.2 Level AA
- Branch: feat/aios-149-accessibility-audit
- Primary flows:
  - Authentication
  - Operational dashboard
  - Interactive office
  - Agent inspector
  - Reduced-motion mode
  - WebGL-unavailable fallback
- Automated engine: axe-core through Playwright
- Manual screen reader baseline: NVDA with Chrome or Firefox
- Status: implementation pending final evidence

## Source requirements

The interactive 3D office must have an equivalent keyboard-accessible dashboard,
timeline, action interface, and WebGL fallback. Simulation state must remain
visibly and programmatically distinguishable from verified execution.

## Findings

| ID | Area | Finding | Severity | Resolution |
|---|---|---|---|---|
| A11Y-001 | Landmarks | Operations and office pages nested a second main landmark inside the application main landmark. | High | Replace page-local main wrappers with div elements. |
| A11Y-002 | Navigation | Authenticated pages did not expose a bypass link for the repeated sidebar. | High | Add a global Skip to main content link and stable focus target. |
| A11Y-003 | Automation | Browser tests did not run WCAG-specific automated checks. | High | Add @axe-core/playwright and release-blocking critical-flow scans. |
| A11Y-004 | Focus | Light-mode ring token was too close to the background for a dependable indicator. | Medium | Strengthen light and dark focus-ring tokens. |
| A11Y-005 | Contrast | Dark sidebar primary foreground matched its background token. | High | Correct the dark foreground token. |
| A11Y-006 | Motion | Reduced-motion behavior existed in the office but not as a global CSS safeguard. | Medium | Add a prefers-reduced-motion override for nonessential CSS motion. |
| A11Y-007 | 3D equivalence | AIOS-134 already provides a DOM inspector, keyboard bridge, focus return, and dashboard fallback. | Pass candidate | Preserve and verify with Playwright and manual screen-reader testing. |

## Manual keyboard audit

- [ ] First Tab exposes Skip to main content.
- [ ] Enter moves focus to the main content landmark.
- [ ] All sidebar destinations are reachable by keyboard.
- [ ] Focus order follows the visual and semantic order.
- [ ] Focus indicators remain visible in light and dark modes.
- [ ] No focused element is fully obscured by sticky or overlay content.
- [ ] Office room navigation supports arrows, Home, End, Enter, and Space.
- [ ] Escape closes the inspector.
- [ ] Inspector focus returns to the exact triggering control.
- [ ] No keyboard trap exists in dialogs, menus, sidebar, or canvas bridge.

## Manual screen-reader audit

- [ ] Page title describes the current page.
- [ ] One main landmark is announced.
- [ ] Headings form a meaningful hierarchy.
- [ ] Refresh status updates are announced without moving focus.
- [ ] Simulation and Unverified labels are announced.
- [ ] Operational tables expose captions, row headers, and column headers.
- [ ] Office keyboard instructions are discoverable.
- [ ] Agent inspector has a name and description.
- [ ] WebGL fallback exposes the same projected state and dashboard action.
- [ ] Icon-only controls have accessible names.

## Manual visual audit

- [ ] Normal text meets at least 4.5:1 contrast.
- [ ] Large text meets at least 3:1 contrast.
- [ ] Focus indicators and control boundaries meet non-text contrast requirements.
- [ ] Status is not communicated by color alone.
- [ ] Content remains usable at 200% browser zoom.
- [ ] Content remains usable at a 320 CSS pixel viewport.
- [ ] Table overflow remains intentionally horizontal without hiding actions.
- [ ] Pointer targets meet WCAG 2.2 minimum target-size requirements.

## Reduced-motion audit

- [ ] Enable the operating system Reduce Motion preference.
- [ ] Reload the office.
- [ ] Reduced motion enabled is announced and visible.
- [ ] Camera travel is disabled.
- [ ] Agent bobbing, pulsing, and turning are disabled.
- [ ] CSS transitions complete immediately.
- [ ] Workflow state and controls remain unchanged.
- [ ] No required information depends on animation.
